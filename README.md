## ⚙️ Installation

1. Install Python.

2. Clone this repository.

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Run a Python project:

   ```bash
   python Student_Performance_Graph.py
   ```

Replace the filename with the project you want to run.
